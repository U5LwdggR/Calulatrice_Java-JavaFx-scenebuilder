Bonjour pour pouvoir importer ce mini projet dans votre IDE, vous devez:
- Telecharger et installer JDK version 21 LTS
- Telecharger et installer openSDK version 21
vous pouvez realiser ces telechargements depuis les sites officiels de ces differentes technologies.
pour l'installation de openSDK 21 dans l'ide(eclipse):
- decompresser openSDK 21,
- ouvrez votre ide et faites un clique droit sur le projet,
- cliquez sur build path, puis sur configure build path,
- cliquez sur Libraries puis sur modulePath,
- cliquez sur add Library puis sur user library et sur user libraries
- cliquez sur la seul user library que vous verrz puis sur add external jars,
- et deplacez vous vers le opensdk que vous avez decompresse, entrez a l'interieur puis dans le dossier lib
- enfin selectionner tous les fichiers jars et cliquez sur apply and close
